# arnavnandurkar.github.io


This is my personal website. It is built as a 3D rendering of Rivendell, and the contents of the website are accessed through navigating the model. The UI is inspired from The Elder Scrolls V- Skyrim. Navigation is done by scrolling. The model was made by me using creative commons licensed assets (a list of complete models used with credits is in the About section of the website.
Three.js is the framework used for the website.
